# Layout sync (`kbsync`)

One canonical layout, generated onto every keyboard. Design:
[`docs/superpowers/specs/2026-09-15-layout-sync-design.md`](../../docs/superpowers/specs/2026-09-15-layout-sync-design.md).

```
base.yaml            canonical layout: layers (corne42 grid), combos, timing, firmware features
boards/<board>.yaml  per-board profile: firmware, output file, position map, overrides
kbsync/              Python package (keys vocabulary, ZMK codec, CLI)
tests/
```

**Edit `base.yaml`, then regenerate.** Generated firmware files carry a
`GENERATED by kbsync` header; hand edits there are overwritten.

```sh
cd shared/layout
python3 -m kbsync.cli gen corneish-zen            # write the board's .keymap
python3 -m kbsync.cli gen corneish-zen --check    # exit 1 if out of date
python3 -m kbsync.cli import-dump corneish-zen ../../keyboards/corneish-zen/zen_keymap.json
python3 -m kbsync.cli verify-dump corneish-zen ../../keyboards/corneish-zen/zen_keymap.json
python3 -m pytest -q
```

Vial boards are programmed live over USB (needs `brew install hidapi`):

```sh
python3 -m kbsync.cli push corne-ec --dry-run     # plan only
python3 -m kbsync.cli push corne-ec               # backup -> write -> read back + verify
python3 -m kbsync.cli restore corne-ec <backup.json>
```

(`uv run kbsync …` works too.)

## Positions

`{L|R}{row}{col}` — row 0 top, 1 home, 2 bottom, 3 thumb; col 0 = outermost.
Grids in `base.yaml` are written in physical order (left half outer→inner,
right half inner→outer).

## Keys

Lowercased ZMK names (shortest non-deprecated alias): `lctrl`, `lbkt`, `c_pp`,
`globe`. Modifiers: `ctrl+alt+shift+cmd+key` (plus `r` variants).
Unnamed usages: `consumer(0x71)`. Behaviors: `mo(layer)`, `mt(lctrl, z)`,
`lt(layer, key)`, `bt_sel(0)`, `bt_clr`, `studio_unlock`, `trans`, `none`.

`kbsync/data/zmk_keys.json` is generated from ZMK's `dt-bindings/zmk` headers:
`python3 -m kbsync.cli zmk-table <zmk>/app/include/dt-bindings/zmk`.
